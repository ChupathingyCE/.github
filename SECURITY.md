# Security

Found a way to hurt players, hosts or our servers? Please tell us privately
first, so we can fix it before it's public.

## How to report

- **On GitHub:** open the repository's **Security** tab and choose
  **Report a vulnerability**. Only the maintainers see it.
- **No GitHub account?** Message a Developer privately on our Discord.
  Please don't post details in public channels.

Tell us what you found, which build and platform, and how to reproduce it.

## What's covered

- The latest Chupathingy release and the current test build.
- The latest console builds.
- Our dedicated server, the Delta services and stats.chupathingy.org.

Older releases aren't patched; the fix ships in a new release.

## What happens next

We reply as soon as we can and keep you posted. Security fixes ship as
their own release right away, with a plain note on what was fixed and what
to do. We credit you in the release notes if you'd like.
